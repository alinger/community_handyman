## 一、提审填写信息

### 小程序简介（功能介绍栏，可直接粘贴）

> 邻有回应是一款面向小区住户的社区生活服务预约小程序。用户可选择「上门代倒垃圾」（包月或按次）与「宠物上门遛弯」（按时长档位）两项服务，选择服务地址与上门时段后提交预约，由社区认证的上门服务人员按预约上门服务；服务过程有打卡与照片记录，用户可在订单内查看进度并确认完成。小程序同时提供地址管理、订单管理、服务进度查看等配套功能。

### 服务类目建议（微信公众平台 → 服务类目）

| 服务 | 建议类目 | 说明 |
|---|---|---|
| 代倒垃圾 | 生活服务 - 家政/保洁服务 | 主营类目 |
| 遛宠服务 | 生活服务 - 宠物服务（若无此三级类目则选 生活服务-其他生活服务） | 以 mp 后台实际可选为准 |

**本次审核不涉及**：支付（试运行期下单免收款，未接入微信支付）、医疗（陪诊未开放）、未成年人相关（接送小孩未开放）。

## 二、审核员可体验的功能路径

### 住户侧
1. 打开小程序即可以游客身份浏览首页（不强制登录）
2. 首页选择「代倒垃圾」/「遛宠服务」→ 提示登录（用测试账号登录）
3. 预约页：服务地址（已预置，可编辑）→ 服务时间（日历选日期+时段）→ 服务方案/时长档位 → 垃圾类型/备注 → 提交预约（免支付，直接进入「待接单」）
4. 「订单」查看列表与详情：进度节点、费用明细、订单号
5. 「我的」：个人信息、常用地址管理（新增/编辑/设默认）、服务记录查看

### 服务方侧（切换方式：「我的」页 → 身份视角切换）
1. 切换为服务方视角后进入工作台：接单池 / 我的任务
2. 接单池抢单 → 任务出现在「待服务」
3. 遛宠任务：点「开始服务」→ 拍照上传上门凭证（必填，可多张）→ 进入服务中；点「完成服务」→ 可选拍照 → 提交待住户确认
4. 垃圾任务：出发上门 → 完成服务（可选拍照）
5. 住户侧回到订单点「确认完成」→ 服务报告（打卡时间 + 影像记录）

## 四、审核风险点与规避建议（重要）

### 1. 服务范围限制（最大风险点）
预约地址仅面向试点小区（东方冠郡等 12 个小区，上海浦东），**审核员所在地填地址会提示「不在服务范围」**，无法走通下单闭环。
**规避方案（建议同时做）**：
- 测试账号预置好有效地址与若干历史订单，审核说明中注明「服务目前仅面向试点小区」
- 提审期间在后台临时放宽：服务范围校验放行审核所在城市/临时小区，或关闭范围校验开关（审核通过后收紧）

### 2. 双身份演示链路
完整体验需要住户+服务方两个身份。服务方身份需通过资质认证，**务必给审核提供已认证的服务方测试账号**，并在测试说明中写清切换入口（我的 → 身份视角）。

### 3. 支付（当前无风险）
生产环境 `PAYMENT_SKIP_PAY=true`：下单即视为已支付，不出现任何支付界面。**提审版本不应接入微信支付**（否则需先开通商户号并补支付类目资质）。接入后需更新本说明。

### 4. 敏感服务已隐藏（有利）
陪诊（涉医疗资质）、接送小孩（涉人身安全）入口均为「敬请期待」，点击仅提示、不进入任何功能页，不参与本次审核范围。

### 5. 用户隐私保护指引（提审前置必做）
微信公众平台 → 设置 → 服务内容声明 → 《用户隐私保护指引》需声明以下收集项，否则相关接口（相机/相册等）会被驳回：
- 手机号：注册登录与联系服务
- 地址信息：上门服务派单
- 宠物信息（用户自行填写）：服务准备
- 相册/摄像头：上传服务凭证与现场记录

### 6. 手机号登录合规
游客态可浏览首页与服务介绍，仅在**预约下单**时要求登录（服务必需场景），符合「不得强制」要求。

### 7. 内容安全
无社区/评论等 UGC 场景；用户备注为订单私有字段（仅本人与服务方可见），后台可管理。

- [ ] 《用户隐私保护指引》已配置并生效
- [ ] 类目已选（生活服务-家政 + 宠物相关），主体资质符合类目要求
- [ ] 小程序名称/头像/简介与实际功能一致
- [ ] 生产 `PAYMENT_SKIP_PAY=true` 保持不变（审核期间不要开支付）

## 附：当前版本核心功能一览

- 预约时段：后台「时段库存」按日期配置全天 12 时段，用户任选，满员置灰
- 代倒垃圾：包月 ¥30/30 天（按日核销）+ 按次 ¥5（赠送次数抵扣）；备选服务时间取代默认取件时间

- 服务凭证：开始服务必传（可多张）、完成服务选传，按「开始/完成/过程」分组展示
- 改期：住户申请 / 服务方申请（住户确认）；拒单自动退款
- 后台：看板、订单（导出/代客操作）、时段库存、SKU 档位配置、服务范围、用户、资质审核、财务、核销、账号
